# Impression

A camera that turns what it sees into dots — and plays them as sound.

## How to use it

**1. Open it.** Allow the camera. Tap the screen once (this turns sound on).
Tap the speaker icon to unmute.

**2. Turn on the mask** (4th icon). Now the picture only appears inside a letter.
Swipe left or right to change the letter.

**3. Point it at something.** Dots appear, and each new dot makes a sound.

**4. Press the big button** to freeze the picture.

**5. Press play.** A line sweeps across and plays the dots as music. High dots
are high notes. Drag the big dial to scrub through it by hand.

**6. Press the button again** to go back to the camera.

## The controls

**Top icons:** brightness helper · invert · sound settings · mask on/off · mute

**Small dials:** RES (dot size) · (ρ) (how many dots) · EXP and CONT (brightness
and contrast)

## Good to know

- The mask starts off. Turn it on — that's the whole idea of the app.
- While a picture is frozen, some controls are greyed out. Go back to the camera
  to use them.
- **Sound settings:** four dot shapes each play a different instrument. Turn the
  left wheel to pick a shape, the right wheel to pick its sound. Set the right
  wheel each time you move the left one, or you'll overwrite the others.

## Put it on your phone

Open the link in Safari → Share → Add to Home Screen. It works offline after
the first time.

## Run it yourself

```bash
npm install
npm run dev      # while working on it
npm run build    # make the real version
npm run serve    # run the real version (works offline)
```

The camera needs HTTPS. See [DEPLOY.md](DEPLOY.md) to put it online.
